# Prochaines étapes recommandées

1. **Créer la cartographie du SI.** Partir de `cartographie_SI/REFERENCE_CARTOGRAPHIE_SI.md`, représenter les zones, puis indiquer les dépendances et les actifs prioritaires.
2. **Mettre la chronologie au format de rendu.** Transformer `CHRONOLOGIE_PREUVES.md` en tableau paysage avec les décisions et les fausses pistes écartées.
3. **Rédiger le communiqué.** Utiliser seulement les faits prouvés et les décisions déjà prises ; faire valider par la Direction.
4. **Construire le plan 30/60/90.** Associer chaque action à un risque, un responsable, une échéance et un indicateur.
5. **Préparer la présentation finale.** Utiliser le format « rapport d'incident », répartir la parole entre les six pôles et répéter les réponses aux questions sur les preuves, les fausses pistes et les décisions.
