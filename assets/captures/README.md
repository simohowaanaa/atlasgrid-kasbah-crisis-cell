# Captures centralisées

Ce dossier est la source unique de toutes les images du dépôt. Les documents Markdown et les fiches de pôles y font référence, sans dupliquer les fichiers.

## Organisation

- `contexte/` : dossier de prise de poste et contexte de l'exercice ;
- `preuves/` : les pièces qualifiées comme preuves ;
- `fausses_pistes/` : les pistes investiguées puis écartées ;
- `bruits/` : les signaux sans lien établi avec MIRAGE ;
- `decisions/` : les douze arbitrages de la cellule, du confinement initial à la reprise progressive des clients.

Les copies archivistiques A-20 et A-13 ont été retirées : elles n'apportaient pas de nouvel événement ni de nouvelle information. La première revendication DarkAtlas est conservée, car elle est distincte de son analyse d'invalidation.
