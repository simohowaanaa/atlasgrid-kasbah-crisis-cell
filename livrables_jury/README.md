# Livrables du jury

Les documents ci-dessous sont classés par usage. Ils complètent l'analyse détaillée présente dans [`dossier_incident/`](../dossier_incident/).

| Usage | Document | Description |
|---|---|---|
| Retracer l'incident | [Chronologie jury](01_chronologie/Chronologie_Jury.pdf) | Chronologie consolidée prête à présenter. |
| Vérifier le détail | [Chronologie complète](01_chronologie/Chronologie_Consolidee_Complete.pdf) | Version détaillée de la chronologie avec les pièces. |
| Organiser la reprise | [Plan de containment et continuité](02_continuite/Plan_Containment_Continuite.pdf) | Mesures de confinement et de reprise des activités. |
| Évaluer les risques | [Tableau de risques](03_risque_conformite/Tableau_Risques.pdf) | Risques, niveaux de priorité et mesures de traitement. |
| Porter le récit de crise | [Rapport d'incident](04_direction/Rapport_Incident.pdf) | Synthèse destinée à la direction. |
| Construire l'après-crise | [Plan de remédiation 30 / 60 / 90 jours](04_direction/Plan_Remediation_30_60_90.pdf) | Actions, priorités et échéances de remédiation. |
| Reproduire le rapport détaillé | [Source LaTeX](05_source_latex/RAPPORT_INCIDENT_ATLASGRID.tex) | Source du rapport de travail avec les captures. |

Les documents reflètent les décisions finales : refus de payer, reprise depuis l'air-gap de Settat, priorité à l'ERP et réouverture progressive des services clients.
